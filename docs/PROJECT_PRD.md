# Product Requirements Document (PRD): AutoCut & Caption
**Phase:** Local Development (MVP)
**Target:** Content Creators & Video Editors (เตรียมพัฒนาเป็น SaaS)

## 1. Project Vision
ระบบ Web Application ช่วยทุ่นแรงการตัดต่อวิดีโอ โดยเน้นการหาช่วงความเงียบ (Dead Air) และถอดเสียงเป็นซับไตเติล (Word-level timestamps) 
จุดเด่นของระบบคือความโปร่งใส (Glass Box) ผู้ใช้ต้องมีอำนาจตัดสินใจขั้นสุดท้ายว่าจะตัดหรือเก็บช่วงเวลาไหนไว้ และผลลัพธ์สุดท้ายจะเป็น "ไฟล์แยก (Export Package)" เพื่อนำไปทำงานต่อในโปรแกรมอื่น เช่น CapCut หรือ Premiere Pro ได้อย่างอิสระ

## 2. Core Features (MVP)
1. **Video Upload:** รองรับไฟล์ `.mp4`
2. **Audio & Silence Analysis:** ดึงเฉพาะเสียงออกมาวิเคราะห์หาช่วง Dead Air แจ้งพิกัดเวลาเริ่มต้นและสิ้นสุด
3. **Word-Level Transcription:** ใช้ AI ถอดเสียงพร้อมระบุเวลาของแต่ละคำ และจัดกลุ่มคำ (Chunking) เพื่อสร้างเป็นบรรทัดซับไตเติล
4. **Interactive Editor (React UI):**
   - แสดงรายการช่วง Dead Air ให้ผู้ใช้ติ๊กเลือก (Checkbox) ว่าต้องการตัดจุดไหนทิ้งบ้าง
   - แสดงรายการซับไตเติลให้แก้ไขคำผิด
5. **Smart Export Engine:** 
   - รับคำสั่งพิกัดการตัดต่อจากผู้ใช้ สั่งการให้ตัดวิดีโอและเสียง "โดยไม่ Render ภาพใหม่" (Fast Slice)
   - สร้างไฟล์ `.srt` จากซับไตเติลที่แก้ไขแล้ว
   - แพ็กไฟล์ทั้งหมด (Video, Audio, SRT) เป็นไฟล์ `.zip` สำหรับดาวน์โหลด

## 3. User Flow
1. อัปโหลดวิดีโอหน้าเว็บ -> รอประมวลผลเบื้องหลัง
2. ระบบโชว์หน้า Editor -> ผู้ใช้รีวิวความเงียบและซับไตเติล
3. ผู้ใช้กดยืนยัน Export -> ระบบตัดวิดีโออย่างรวดเร็วและแพ็กเป็นไฟล์ Zip ให้ดาวน์โหลด
